## Как использовать

Родительный падеж показывает, **чей** предмет. Он отвечает на вопрос **хэний?** (чей?).
Суффикс получает владелец, и он стоит **перед** тем, чем владеет.

| Үгийн төгсгөл                        | Дагавар | Жишээ                                    |
| ------------------------------------ | ------- | ---------------------------------------- |
| Гийгүүлэгч, эр үг (а, о, у)          | -ын     | ном → ном**ын**, Бат → Бат**ын**         |
| Гийгүүлэгч, эм үг; ж, ч, ш, г, ь-ээр | -ийн    | багш → багш**ийн**, ээж → ээж**ийн**     |
| Хос эгшиг (-ай, -ой)                 | -н      | далай → далай**н**, нохой → нохой**н**   |
| Урт эгшиг                            | -гийн   | дүү → дүү**гийн**, Нараа → Нараа**гийн** |

У некоторых слов есть «скрытое н», и они получают **-ны / -ний** (ус → усны). Их вы
изучите на следующем уровне.
