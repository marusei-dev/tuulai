## Как использовать

На уровне M1 у этого падежа две основные задачи:

1. **Место — где?** (хаана?): _гэрт_ — дома, _сургуульд_ — в школе.
2. **Получатель — кому?** (хэнд?): _ахад өгөх_ — дать старшему брату.

| Үгийн төгсгөл           | Дагавар  | Жишээ                                          |
| ----------------------- | -------- | ---------------------------------------------- |
| Ихэнх үг                | -д       | сургууль → сургууль**д**, дүү → дүү**д**       |
| г, р, с, в-ээр          | -т       | гэр → гэр**т**, Улаанбаатар → Улаанбаатар**т** |
| ж, ч, ш, д, з, т, х-ээр | эгшиг+-д | ах → ах**ад**, багш → багш**ид**               |
