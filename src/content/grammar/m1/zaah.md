## How to use

The accusative marks the **object** of a verb – the thing or person the action is
done to. It answers **юуг?** (what?) and **хэнийг?** (whom?).

Mongolian has no word for "the" or "a". Instead:

- **with the suffix** the object is specific: _Би номыг уншсан._ – I read **the** book.
- **without it** the object is general: _Би ном уншсан._ – I read **a** book / I did some reading.

| Үгийн төгсгөл                        | Дагавар | Жишээ                                  |
| ------------------------------------ | ------- | -------------------------------------- |
| Гийгүүлэгч, эр үг (а, о, у)          | -ыг     | ном → ном**ыг**, ус → ус**ыг**         |
| Гийгүүлэгч, эм үг; ж, ч, ш, г, ь-ээр | -ийг    | багш → багш**ийг**, ээж → ээж**ийг**   |
| Урт эгшиг, хос эгшиг                 | -г      | ширээ → ширээ**г**, нохой → нохой**г** |
